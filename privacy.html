NiniOS Alerts: Privacy Policy

Last updated 08/11/2026

Who uses it

NiniOS Alerts is a private tool used by one business for its own bookkeeping. Only the business's own mailbox is connected to it. It is not offered to the public.

What it reads

With the mailbox owner's permission (Google's read-only Gmail access), it looks only for credit-alert emails sent by the business's bank. From each one it keeps the amount, the date and time, the account, the sender's name and the transaction reference.

What it never does

  • It never sends, changes, moves or deletes any email.
  • It never reads other email for any purpose beyond finding those bank alerts.
  • It never sells, shares or passes on any data, and never uses it for advertising.

Where the data is kept

The alert details are kept on the business's own server and shown only to its own signed-in staff. Google's sign-in token is stored on that server and is used only to read those alerts.

Google API data

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

The mailbox owner can withdraw access at any time from their Google Account, under Security, then Third-party apps and services.
